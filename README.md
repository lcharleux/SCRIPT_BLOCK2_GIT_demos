# Publishing LaTeX PDF with GHP import

A simple demo of GHP import as a solution to publish compiled files (PDF in this example) without monitoring them with GIT.

## Install

GHP import can be installed with the Python ecocystem using pip. See the project's page [here](https://pypi.org/project/ghp-import/).

## Upload documents

To upload your docs, you can run the script that is at the root of the repo:

`./scripts/compile_and_publish.sh`
